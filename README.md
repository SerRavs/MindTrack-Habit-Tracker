# MindTrack — Habit Tracker & Gratitude Journal

MindTrack is a Flutter-based application that combines habit tracking, personal productivity analytics, and gratitude journaling to encourage consistent habits and positive daily reflection.

## Features

- **Gratitude Gate:** Encourages users to reflect on three things they are grateful for before entering the application.
- **Smart Habit Tracker:** Allows users to create and monitor daily habits using a calendar-based interface.
- **Analytics Dashboard:** Displays habit completion statistics and progress.
- **Digital Journal:** Provides a space to record daily thoughts and reflections.
- **Gratitude Jar:** Stores past gratitude entries and allows users to revisit positive memories.

## Technologies Used

- Flutter
- Dart
- Visual Studio Code
- table_calendar
- intl
- google_fonts
- cupertino_icons

## Running the Project

1. Install Flutter and Dart.
2. Clone this repository.
3. Navigate to the project directory.
4. Run `flutter pub get`.
5. Run `flutter run -d chrome` to launch the application in Chrome.
